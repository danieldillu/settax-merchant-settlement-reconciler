# settax-merchant-settlement-reconciler
**SettAx – Merchant Settlement Consolidator & Reconciliation Tool**

SettAx is a lightweight, offline Windows desktop application built with Python to simplify merchant settlement accounting and reconciliation.

Designed initially for PhonePe merchant reports, SettAx automatically processes multiple CSV files or ZIP archives, consolidates daily transactions, calculates gross collections, processing fees, GST, recurring charges, and other deductions, and generates structured Excel reports.

**Key Features:**
- Bulk CSV and ZIP file imports
- Automated settlement consolidation and reconciliation
- UPI, card, wallet, and other payment classifications
- Processing fee, GST, and recurring charge calculations
- Duplicate detection and validation notices
- Missing settlement date identification (excluding Sundays)
- Financial dashboard with gross, deductions, and net settlements
- Excel (.xlsx) and CSV exports
- Light and dark themes
- Standalone Windows executable with an optional installer

SettAx reduces repetitive accounting work, improves financial reporting accuracy, and provides clear, auditable settlement summaries without requiring internet access, cloud services, or AI APIs.

**Technology:** Python, Tkinter/ttk, PyInstaller

**Development:** Human-directed, AI-assisted software project.

*Current version: v1.7 (Beta)*
